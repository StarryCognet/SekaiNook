# SekaiNook · 家庭财务与行为管理

一套专为家庭设计的「行为与积分银行 SaaS」。通过量化家务（赚钱）、电子产品使用（花钱）、作息与视力（罚款）以及每周学习计划，实现家庭行为的数字化管理。一套代码，多端适配。

## ✨ 功能特性

### 🏠 家庭工作台（积分银行）
- **积分余额**：大数字展示当前总积分，正数绿色、负数红色
- **任务区**：一键打卡赚钱任务（整理房间、洗碗、按时完成作业等）与消费/罚款任务（看 iPad、玩手机、视力下降等）
- **自定义任务**：自由填写类型（赚钱 / 消费·罚款）、名称、价格，创建专属任务
- **历史记录区**：完整积分流水账本，按时间倒序展示
- **今日任务与作息**：实时时钟 + 作息状态提醒（晚于 21:00 触发罚款提示）

### 📅 每周学习计划
- 英语、语文、数学、日常四大类学习目标
- 进度实时统计，未达标灰色、达标绿色高亮
- 支持调整目标数量与打卡

### 🌻 阳光花园・学习乐园（儿童工作台）
专为孩子设计的趣味学习空间，完成学习任务获得「阳光积分」：
- **今日任务**：古诗背诵、语文预习、数学预习、课外阅读等，彩色图标 + 完成动画
- **古诗背诵 / 语文预习**：专项学习页面
- **阳光花园**：装饰自己的花园
- **阳光商城**：用阳光积分兑换奖励
- **我的奖励**：勋章墙 + 成就进度
- **学习记录**：学习历史

## 🛠 技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | React 18 + TypeScript + Vite |
| UI 组件库 | antd 6（PC 端）、antd-mobile 5（移动端） |
| 状态管理 | zustand 5 |
| 后端 | @supabase/supabase-js 2（未配置时自动回退本地 localStorage） |
| 路由 | react-router-dom 6 |
| 图表 | echarts + echarts-for-react |
| 图标 | @ant-design/icons |

## 🚀 快速开始

### 环境要求
- Node.js 18+
- npm 9+

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 生产构建
npm run build

# 预览构建产物
npm run preview
```

### 数据库配置（可选）

项目默认使用本地 `localStorage` 兜底，无需配置即可运行。如需接入 Supabase 云数据库：

1. 复制 `.env.example` 为 `.env`
2. 填入你的 Supabase 项目 URL 与 anon key
3. 执行 `supabase/002_create_family_tables.sql` 建表

```bash
cp .env.example .env
```

## 📁 目录结构

```
src/
├── api/            # 数据访问层（Supabase / 本地兜底）
├── components/     # 通用组件（加载/空/错误态、花园图标）
├── config/         # 业务规则唯一数据源（任务、学习计划、花园配置）
├── layouts/        # 主布局（侧边栏）、花园布局
├── store/          # zustand 全局状态
├── theme/          # 设计令牌（颜色/间距/圆角）
├── types/          # TypeScript 类型定义
├── utils/          # 工具函数（设备判断、ISO 周计算）
└── views/
    ├── family/     # 家庭工作台、每周学习计划
    └── garden/     # 阳光花园儿童工作台（8 个页面）
```

## 🧭 路由

| 路径 | 页面 |
|------|------|
| `/` | 自动跳转 `/family` |
| `/family` | 家庭工作台（积分银行） |
| `/family/plan` | 每周学习计划 |
| `/garden` | 阳光花园・学习乐园 |

## 📜 业务规则

### 赚钱任务（正数）
| 任务 | 积分 |
|------|------|
| 整理房间 | +10 |
| 洗碗 | +5 |
| 洗衣服 | +15 |
| 倒垃圾 | +5 |
| 按时完成作业 | +20 |
| 课外阅读 30 分钟 | +10 |
| 按时睡觉 | +10 |

### 消费 / 罚款（负数）
| 任务 | 积分 |
|------|------|
| 看 iPad 30 分钟 | -10 |
| 玩手机 30 分钟 | -10 |
| 视力下降 1 度 | -100 |
| 未按时作息（晚于 21:00） | -20 |
| 作业未完成 | -50 |

弹窗要不要盖住顶部栏和底部栏？

左边是真机尺寸的模拟。点手机里的按钮弹出各种窗，再拨下面两个开关对比： 「旧层级」是弹窗被顶栏/底栏压住的样子，「标层级」把每一层描出来。

对比开关

旧层级（弹窗被两条栏压住）
顶栏、底栏画在遮罩之上 → 弹窗看着像只在内容区里
标出层级
黄色=顶栏，紫色=底栏，红色=遮罩，绿色=面板

我想确认的三件事

  • 遮罩盖住整屏：顶栏和底栏都要变暗/模糊，不能再亮着。
  • 面板在遮罩之上：底部面板直接从屏幕底边升起，压住胶囊底栏，而不是停在底栏上沿。
  • 遮罩吃掉点击：弹窗开着时，顶栏的铃铛、底栏的导航都点不动。

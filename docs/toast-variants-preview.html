换语气看看

项目里 toast 有四种 Tone：普通 / 成功 / 警告 / 错误。切一下，看当前这版在别的语气下的样子。

这版的具体参数

位置底部，浮在底栏上方
圆角20（AppCorner.lg）
内边距14 / 12
图标18，左
字号15（subheadline）
停留3 秒（警告 5 秒）
操作有（撤销 / 重试）
顺带一个发现：蓝主题里「错误」不是红、「警告」不是黄。 项目的语义色会被主色相拉一半 —— 晴空蓝下 错误 = #A345E9（紫）、 成功 = #0F9B99（青）、 警告 = #2AF523（亮绿）。

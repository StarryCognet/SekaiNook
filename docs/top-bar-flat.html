顶栏 · 第 3 版

不要胶囊了，就是一条普通的通栏

胶囊那版的问题是它「浮」着 —— 左右各留 16dp、四角全圆，像一颗药丸贴在天花板上，不像大多数 App 顶上那条。 这次全部改成通栏：左右贴边、直上直下、高度 52dp。四版的区别只在「底色什么时候出现」和「有没有那条线」。 手机壳能滚，滚一下就能看出差别。

A 通栏 · 恒定底色
最常见的做法：顶栏永远是白的，底下一条 1px 分隔线，内容从线下面滚过去。
B 通栏 · 首屏透明
延续你要的「融入背景」：首屏什么都没有，往下滑 8dp 才淡出白底和分隔线。
D 大标题式
Material 3 的常规做法：首屏是个大标题，滚动后收成普通 52dp 条。
01

为什么胶囊看着不像顶栏

同样是「图标 + 标题 + 两个按钮」，形状决定它读起来是「一条栏」还是「一颗药丸」。

现在的胶囊 2.9.7

左右各留 16dp，四角 24dp 全圆，再加落影 —— 它和屏幕边框之间有空隙，所以眼睛读到的是「浮在页面上的一块东西」。

↑ 左右有空隙 · 四角全圆

通栏 这一版

左右贴到屏幕边，高度 52dp，底部一条 1px 线把它和内容分开 —— 这才是「顶栏」的形状，和状态栏连成一体。

↑ 贴边 · 矩形 · 底部一条线

A 通栏 · 恒定底色
最常见的顶栏：永远是白的，一条 1px 分隔线。滚不滚都一样，最稳、最不容易被说「怪」。
A 的特点：最「普通」

你打开任何一个 App，顶上十有八九是这条：通栏白底 + 底部 1px 线，标题左边 16dp，右侧图标 16dp。

好处是没有状态切换 —— 不管你滚不滚、页面是什么颜色，它都长一样，不会突然变。

代价

首屏会占掉 52dp 高，页面内容整体往下让。你之前想要的「首屏完全融入背景」就没有了。

B 通栏 · 首屏透明
形状是通栏，但首屏不留痕迹；往下滑 8dp，白底和那条线一起淡进来（280ms）。
B = 你原来要的效果 + 普通的形状

首屏真的什么都没有（无底色、无线、无影），滚起来才长出一条栏。和 2.9.7 的区别只是形状从胶囊换成通栏，不加左右空隙、不加圆角。

这条最可能是你想要的那条。

首屏状态

内容第一行在 99dp 处开始（47 状态栏 + 52 条），滚动时内容从条下面穿过去。因为形状是通栏，穿过去的时候左右不会露边。

C 通栏 · 只靠阴影
同上，但滚动后不加那条 1px 线，只用一层淡阴影把它托起来。
C 和 B 的差别只有一处

B 滚动后出现 border-bottom: 1px；C 不画线，只加 box-shadow: 0 2px 10px rgba(40,20,25,.10)。

有线的版本边界更硬、更「系统」；只有影的版本更软，但深色主题下阴影几乎看不见，容易糊在一起。

深色主题下要注意

深色底上黑影不可见，C 版滚动后等于「顶栏突然变白（深灰）」而没有分隔，内容会看着有点脏。深色下建议还是保留那条线 —— 也就是 B。

D 大标题式（Material 3）
首屏是个 31px 的大标题贴在内容里，顶上那条只剩两个按钮；滚上去后大标题收起、小标题出现、底色长出。
D 的代价

最「现代」，但要改的地方最多：每个页面都得单独摆大标题，还要算大标题和滚动条的联动。而且这个项目没多少页面适合大标题（任务页、设置页还行，花园页和计划页很难摆）。

我的建议

如果你要的是「看着普通、别搞花样」，选 B —— 形状是通栏，首屏还是干净的，改动也只是把 2.9.7 的胶囊换成矩形条。

03

落地数值（选哪版都按这套）

和 2.9.7 的胶囊相比，几何只有三处变化。

项2.9.7 胶囊通栏（新版）说明
左右外边距edgeMargin 160贴到屏幕边；内容自己的左右 16dp 留白保持不变
圆角AppShape.pill()0矩形。只在底部画线或加影
高度48dp52dp通栏没有内壁，52 是「52 - 0 = 52」，图标与文字都居中
底部边界落影1px 分隔线（B / D）或阴影（C）线用 palette.border
内容内壁上下 6 / 左右 18上下 0 / 左右 16内容离屏幕边 = 16 + 0 = 16dp（和页面正文对齐）
滚动阈值8dp8dp（B / C / D）A 版不需要这个逻辑
过渡240ms280ms底色和线一起淡入
改动量（选 B 的话）

只动 app/lib/ui/shell/app_top_bar.dart 一个文件：把 Padding(horizontal: edgeMargin) 去掉、AppShape.pill() 换成 BoxDecoration 矩形 + Border(bottom: ...)、innerHeight 48→52、内壁改成 EdgeInsets.symmetric(horizontal: 16)。外壳的滚动监听、明暗三档按钮、顶部渐隐层全部复用，不用动。

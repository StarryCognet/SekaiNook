顶栏为什么显厚重，改法有四种

我把现在这条顶栏按真实尺寸放大了 1.75 倍来拆，问题集中在三个地方：52dp 的胶囊里只有 3 个字、 左右两端轻重差太多、落影是两层叠出来的灰雾。下面是五张手机壳（现状 + 四版），可以直接点着看。

现状占位
顶栏本体 52dp，比下面几版都高
最省事的改法
A 版：高度 52→42、去掉左侧色块、阴影减到一层
我个人推荐
A 版观感 + B 版的「首屏通透、滚动才浮现」

03

我推荐 A + B 的组合

A 的形状（矮一些、图标不带底、阴影只留一层）+ B 的行为（首屏不加底、滚动才浮现）。 这样观感最轻、代码改动也可控 —— 顶栏本来就是个纯展示组件，改的都是装饰参数。

推荐版 · 42dp 胶囊 + 单层落影，首屏即可；滚动超过 8dp 时胶囊底从透明淡入（B 的行为）

具体改什么

全部在 app/lib/ui/shell/app_top_bar.dart 一个文件里，几何常量都在那个类顶部。
  • innerHeight 52 → 42，topMargin 保持 8；比现状省 10dp（contentInset 跟着自动变，两处不用各改一遍）。
  • 删掉左侧 28dp 的 primarySoft 方块，图标直接用 palette.primary 画 19px —— 少一层色块，视线回到文字上。
  • 名字 14 → 15px，w600 不变。胶囊里只有字，字得稍微大一点才不显空。
  • 阴影从两层减到一层：blur 10, y 3, alpha .10（深色 .28）。深色模式本来就该更轻。
  • 右侧两件统一到 36dp：铃铛 40→36，明暗胶囊 52×28 → 46×26，两者垂直居中对齐。
  • （可选 B 行为）首屏不给胶囊底：color 用 Colors.transparent、阴影为空，页面滚动 offset > 8 时用 AnimatedContainer(160ms) 淡入白底 + 阴影。要接一个 ScrollNotification 监听，或者在外壳里传 elevated 布尔。
为什么不动底栏：底栏是 FlClash 那套跟手胶囊，动了就得两处一起调；顶栏是纯展示组件，只改装饰参数，风险小。

五版的代价

按「改几个文件 / 要不要动交互 / 会不会波及别的页面」排。

方案顶栏高比现状省改什么风险
A 瘦身胶囊42dp10dp只改 app_top_bar.dart 的几何常量与装饰低 —— 纯装饰，不影响滚动与路由
A + B 通透42dp10dp上面 + 一个滚动监听（或外壳传 elevated）中 —— 要接 NotificationListener，注意别和下拉刷新打架
C 大标题96dp → 44dp展开时反而更高顶栏重写 + 滚动收缩 + 其它 4 页跟着改高 —— 五页风格要一起换，等于一次视觉改版
D 直线52dp0去掉圆角/阴影/侧边留白，改成贴边 + 底线中 —— 和悬浮底栏语言不再成套
E 极窄38dp14dp顶栏瘦身 + 把明暗开关挪进设置页中 —— 少一个快捷入口，家里老人可能找不到
一句话结论：A 是「不改结构、只改装饰」的最小改动，观感立刻轻一档；想再进一步就叠 B 的滚动浮现。 C 更适合以后整套视觉改版时一起做，现在单改一页会显得突兀。

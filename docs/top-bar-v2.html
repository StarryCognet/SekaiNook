上面这台是真的能滚的 —— 滚轮往上推，看顶栏怎么从"没有"变成"有"。

首屏：真的什么都没有 顶栏只画图标 + 页名，底色是 transparent、shadows: []、没有描边。所以它和页面底是同一块颜色，看不出"一条"。
滚动后：长成胶囊 内容往上走 8dp 之后，background-color 与 box-shadow 一起用 280ms 淡入 —— 不是突然出现一个条，是"浮"出来的。
为什么要有「顶部渐隐」这个开关 注意看：纯透明时，第一张卡滚到顶栏下面会和「任务」两个字叠在一起；打开「顶部渐隐」，页面顶部会有一层从底色到透明的渐变，文字就不会撞内容。这是两套方案，不是必选 —— 你要是喜欢纯透明那种干净，就保持纯透明，反正滚一点就变胶囊了。
上一版没做到的地方 上一版把胶囊高度压到 42dp、内容离屏幕边只有 19dp —— 太窄、太贴边。这一版把胶囊抬回 46–48dp，左右内缩 12–14dp（内容离屏幕边 28–34dp）。
02

三组尺寸，挑一组

差别只在三个数：胶囊高度、胶囊离屏幕边的距离（edge）、内容离胶囊边的距离（pad）。点上面的 A / B / C 就能在 01 那台手机上实时换。

方案胶囊高胶囊离屏边内容内缩内容离屏幕边观感
A 紧凑44dp14dp10dp24dp 最省地方，但比上一版只多 2dp，还是偏"细条"
B 舒缓（推荐）46dp16dp12dp28dp 和底栏胶囊（66dp 高、离边 16）气质一致，不显窄也不显胖
C 宽松48dp20dp14dp34dp 内容收得最进来、最不贴边；但胶囊比页面卡片窄了一圈，会有点"浮"
「内容不要往两边去」指的是这件事 上一版内容离屏幕边只有 16（胶囊边）+ 3（内壁）= 19dp。这次 B 组是 16 + 12 = 28dp，C 组 34dp。你在 01 里切一下 A/B/C，主要看左边的「任务」两个字和右边的铃铛离屏幕边够不够。
03

「渐变融合」是哪三帧

滚动位置 0 → 8dp 触发，动画 280ms、曲线 cubic-bezier(.2,0,0,1)（先快后稳，不弹跳）。

任务☾
0ms · 完全透明
任务☾
约 120ms · 半透明白、影刚起
任务☾
280ms · 不透明胶囊 + 完整影
为什么不做「高度也从 0 长出来」 那样滚动时内容会被顶栏推得跳一下。现在高度始终占着（46dp），只有颜色和影子在动 —— 内容位置一点不变，看起来才是"浮"而不是"长"。

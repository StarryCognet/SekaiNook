## 2. P0（每一条都在真实使用路径上）

### U-01 字号滑杆基本空转（功能级误导）— P0
- 现象：设置里拖「字号」到 80% / 140%，界面正文几乎不变，只有右侧百分比在跳。实拍 `p-ts14-home.png` / `p-ts14-garden.png` 与 1.0 版像素几乎一致。
- 机制：`app/lib/theme/app_theme.dart:516-522` `textTheme: base.textTheme.apply(fontSizeFactor: textScale)`；但全 lib 有 **420 处** `AppFontSize.*` + **374 处** `TextStyle(fontSize:)` 显式字号（`app/lib/theme/tokens.dart:29-38` 写死 12/14/16/20/24/48），显式字号覆盖合并结果，`fontSizeFactor` 对它们零作用。只有 4 处 `textTheme.` 调用，全在预览页。
- 还有第二道闸：`app/lib/fl_ui/typography.dart:70-75` 的 `_apply` 用枚举常量硬覆盖 `fontSize`，把 `fontSizeFactor` 吃掉；同时 `app.dart:235` 的 `MeasureScope` 传的是 `media.textScaler.scale(1)`（不含主题 textScale），**测量与渲染不同源**。这解释了实拍里「按钮文字变大、正文不动」的半截缩放。
- 正确修法（一条链）：`MeasureScope` 传 `media.textScaler.scale(1) * theme.textScale`，`typography._apply` 里 `fontSize: size * factor`，再逐步把业务 `AppFontSize.*` 换成 `textTheme.*`。
- 而设置页 `settings_page.dart:1271` 的说明文案承诺「整体放大或缩小正文」。
- 建议（产品决策二选一）：
  - 便宜：说明改成「仅影响部分组件文字，正文暂不随动」——诚实但难看；
  - 正经：抽 `AppText`（读 `textTheme.bodySmall/bodyMedium`）替换高频正文，分页面推进；**不要**改用 `MediaQuery.textScaler`（注释已说明会撑破固定高度）。

### U-02 通知页自带标题栏与主壳顶栏重叠 — P0
- 证据：`app/lib/ui/pages/home/notifications_page.dart:165-189` 是 `Scaffold > SafeArea > Column`，header 在 Column 第一项，`Padding` 用 `AppSpacing` 没加 `AppTopBar.contentInset`（`:197-203`）；而 `/home/notifications` 在 `app/lib/router.dart:65-70` 的 `ShellRoute` 内，`app/lib/ui/shell/main_shell.dart:219-224` 又把 body 的 `MediaQuery.padding.top` 抹成 0 → 页面 `SafeArea` 顶部让位 = 0。
- 后果：两层标题叠字；右侧「全部已读」（`:245-254`）正好落在顶栏铃铛/明暗两颗 36×36 芯片下方，点击先命中顶栏（穿透到 `/home/notifications` 或切换明暗）。列表又在 `:461-466` 让了一次 `contentInset`，顶部总留白 ≈140dp。
- 实拍：`p-light-notice.png` 可直接看到「🔔 通知」顶栏 + 「← 通知」页面标题。
- 修法：删页面 header 的返回键与标题（顶栏已经显示「通知」），只把「全部已读」放到内容区第一行；或保留 header 但加 `AppTopBar.contentInset`，同时删掉列表里的那一次。正确样例见 `settings_page.dart:2012-2018`。

### U-03 打卡照片上传时弹层可被关掉 → 红屏或整页被 pop — P0
- 证据：`family_dashboard_page.dart:2361` 只把「取消」按钮置灰；但 `SnapSheetRoute` 的 `barrierDismissible => true`（`app/lib/fl_ui/snap_sheet.dart:77`），点遮罩/下拉/返回键都会走 `_dismiss()`（`:91-98`）。
- 两条收尾都在弹层卸载后执行：失败分支 `setDialogState(...)`（`:2379-2382`，对已卸载 State 调 `setState` → 抛错）；成功分支 `if (mounted) Navigator.of(context).pop(...)`（`:2386-2392`，`mounted` 是**页面** State 的，仍为 true → 把 `/family` 页面路由 pop 掉）。
- 修法：底座已有守卫钩子 `SheetDismissScope.of(context)`（`app/lib/fl_ui/inherited.dart:220-233`），上传中返回 `{ if (uploading) return; }`；两处 `mounted` 改成 `builderContext.mounted`。

### U-04 花园「学习记录」全量建 widget + 30s 整页重建 — P0
- 证据：`app/lib/ui/pages/garden/garden_page.dart:1941-1950` 用普通 `for` 把 `garden.cachedRecords` 全量塞进 `Column`（每行还含 2 个 `AnimatedCount`）；数据源 `app/lib/state/garden_state.dart:664-685` `refreshLedger()` **没有 limit**，历史全量入 store；`:694-697` 每 30s `flushPending()` 有改动就 `notifyListeners()` → 页面 `context.watch` 整页 rebuild。
- 后果：记录只增不减，任意一次打卡/同步都重建 N 行；孩子最常看的页面长期掉帧。
- 修法：store 截断（如 50 条）；UI 只渲染前 20 条 + 「查看全部」，或换 `ListView.builder`。

### U-05 家庭页「历史」全量 Column + 每个周标题重扫全表（O(n²)）— P1（性能口）
- 证据：`family_dashboard_page.dart:1745` `visible = filtered.take(_visibleCount)` → `:1794` `_groupedRecordRows` 返回普通 `List<Widget>` → `:1844` 整块塞进一个 `Column`（外层单 child `ListView`，无虚拟化，注释自述上限 500 条）；每个周标题 `:1840` 又把整份 `records` 传进 `_weekHeader`，`:1853-1857` 里再扫一遍全表求合计 → 40 周 × 500 条 ≈ 2 万次迭代 + 4 万个临时 `DateTime`（`_weekStartOf:1882-1885`）。
- 修法：周标题合计在既有循环里顺手累加（签名改 `(week, total)`）；`Column` → `ListView.builder`。

## 10. 修复记录（2026-10-25 全改 · 2.10.0）

### 10.1 结构性整改（第 2/3 批里可做的都做了）
- **U-01 字号机制**：`app_theme` 不再用 `textTheme.apply(fontSizeFactor:)`，改为在 `app.dart` 把字号滑杆折进 `MediaQuery.textScaler`（与系统字号相乘后 clamp 0.8–1.5）。所有 `Text`（含 394 处 `fontSize: AppFontSize.*` 字面量、按钮、导航、弹窗）随之一起缩放，不需要逐处改成 `AppText`。
- **返回栈兜底**：`MainShell` 冷启动落在二级页时补了「无栈可退 → 回 /home」的分支（浏览器历史整合没做，见 10.2）。
- **版心**：`MainShell` body 包 `Align(topCenter) + SizedBox(width= min(maxWidth,720))`（宽屏 720，窄屏不裁）；顶栏同宽；底栏 `Center(heightFactor:1)` 限宽（`heightFactor` 关键：裸 `Center` 会把胶囊摆到屏幕正中）。
- **底栏让位**：`NavigationDock.contentInsetOf` 用 `viewPaddingOf` 修正手势条少让位；各页 `contentInset` 统一走它。
- **U-12 转场**：`theme/motion.dart` 的 `pageTransitionsTheme` 与 `SlidingHighlight` 现在查 `MediaQuery.disableAnimations`；骨架/加载/庆祝/打字机同样。
- **顶栏**：两颗图标按钮 36→44dp、徽标 99+、页名 16/600 可读、`Semantics` 标「当前页面」与按钮作用。
- **弹窗底座**：`fl_ui/dialog.dart` 的 `CommonDialog` 补 `insetPadding: 24` + `scrollable: true`（窄屏不再溢出）、`barrierDismissible` 可由调用方覆盖（上传中不可关）、`_AlertRoute` 居中包 `ConstrainedBox`；`snap_sheet` 加 `SheetDismissScope` 守卫（`side_sheet` 还没，见 10.2）。
